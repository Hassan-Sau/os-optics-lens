# Sony FE collection

This collection contains native `os-optics` Projects transcribed from numerical examples in
Sony-assigned patent publications for photography. Each record names the publication, example,
attribution and redistribution terms. The [series issue](https://github.com/JunLin615/os-optics-lens/issues/13)
tracks contribution review.

Each record directory contains `project.json` and `record.json`. The native Project is the
prescription. The record gives the Project's paraxial EFL and BFL at its native vacuum wavelength.
The full-frame label describes the intended format of the published design. The batch notes
explain the modeled configurations and apertures.
