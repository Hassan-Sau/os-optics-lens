# Sony FE batch 1

Four native Projects represent numerical examples 1, 2, 4 and 5 of Sony Group Corp's
US20240061211A1, “Imaging lens and imaging apparatus.” Example 3 was deferred after the
transcribed prescription gave a substantially different focal length from the printed value.
[US20240061211A1](https://patents.google.com/patent/US20240061211A1/en)

The publication prints an image height `Y` of 21.633 mm for each of the four examples, corresponding
to a nominal diameter of 43.266 mm. Those values describe the patent examples. The Projects leave
usable image-circle coverage unconfirmed.

Each Project represents infinity focus and places the observation plane after the last tabulated
thickness. The materials use constant refractive indices at the reference wavelength. The Projects
use a uniform clear semi-diameter because the publication supplies no semi-diameters. The stop is
marked `STOP_NOT_BLOCKING`, so stop-dependent constraints remain unconfirmed. The direct source
identifies the focus states with closer conjugates.
